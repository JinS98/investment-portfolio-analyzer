# 17주차: 적립식 투자 운영 기준

## 거래 출처

- `수동 기록`: 사용자가 직접 등록한 매수·매도 이력입니다.
- `적립식 자동매수`: 저장된 적립식 규칙에서 생성된 매수 이력입니다. 거래 내역에서 출처 필터와 규칙별 이력 필터로 확인합니다.

## 실행과 소급 반영

- 로그인 후 포트폴리오를 열면 시작일부터 오늘까지 미반영 예정일을 확인합니다.
- 종목의 해당 거래일 종가로 매수 이력을 생성합니다.
- 주말·휴장일은 이후 최초 거래일로 보정하며, 거래 이력에는 원래 예정일과 실제 반영일을 함께 저장합니다.
- 규칙 ID와 마지막 반영일을 저장해 같은 날짜를 중복 반영하지 않습니다.

## 실제 포트폴리오

- 실제 포트폴리오의 자동 반영 건은 `확인 필요`로 표시합니다.
- 토스 체결 단가, 수량, 수수료, 세금을 입력해 확정하면 원장을 다시 계산합니다.
- 규칙을 수정하거나 삭제해도 기존 자동매수 이력은 유지됩니다.

## 비용 정책

- 자동 매수 수수료 기본값은 거래금액의 `0.015%`입니다.
- 매수 세금 기본값은 `0`입니다.
- 실제 포트폴리오 확정 화면에서는 실제 비용으로 수정할 수 있습니다.
