# 1주차: 프로젝트 기반 구성

## 목표

국내·미국 주식 포트폴리오를 기록하고 분석할 수 있는 React 애플리케이션의 개발 기반을 만든다.

## 구현

- React, TypeScript, Vite, Sass 기반 프로젝트와 공통 색상·간격 토큰 구성
- Firebase 초기 연결, 인증 상태 저장소, 포트폴리오 상태 저장소의 초기 구조 마련
- 토스 API 호출 계층과 포트폴리오·시장 데이터 타입 정의
- 대시보드, 기본 계산 유틸, 리스크 계산의 초기 화면과 테스트 환경 구성

## 기준

- 계산 로직은 UI에서 분리하고 TypeScript 타입으로 입력·출력 형태를 고정한다.
- API 키는 로컬 환경 변수로 관리하며 브라우저 코드에 직접 작성하지 않는다.
