# 3일차: 토스 API와 종목 검색 연결

## 목표

개발 서버를 통해 토스 API를 안전하게 호출하고, 사용자 입력으로 종목을 찾을 수 있게 한다.

## 구현

- Vite 개발 서버의 `/api/toss/*` 미들웨어와 토큰 발급·갱신 처리
- 국내·미국 종목 검색 데이터와 검색 결과 UI 연결
- 검색 결과에서 매수 기록 입력으로 이어지는 흐름 구성
- 검색어 정규화, 결과 수 제한, 최근 검색어 동작 검증

## 기준

- 토스 Client Secret은 브라우저 번들에 포함하지 않는다.
- 동일 검색어의 중복 요청을 줄이고 공백·대소문자 차이는 같은 검색으로 처리한다.
