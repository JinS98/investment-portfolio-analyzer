# 16일차: 적립식 투자 자동 반영

## 목표

종목별 주간·월간 적립식 매수 규칙을 만들고, 도래한 거래를 원장에 안전하게 반영한다.

## 구현

- 주간·월간 빈도, 시작일, 수량, 활성 상태를 가진 자동 매수 규칙
- 휴장일 보정과 장기 미접속 시 미실행 예정일 소급 처리
- 거래일 종가·비용을 포함한 자동 매수 원장 생성
- 규칙 생성·수정·삭제 및 예정일 계산 테스트

## 기준

- 자동 매수는 같은 규칙·거래일에 중복 반영하지 않는다.
- 규칙 변경은 과거 거래 이력을 수정하지 않는다.
- 실제 포트폴리오 거래는 체결 확인 전 상태로 남길 수 있다.
