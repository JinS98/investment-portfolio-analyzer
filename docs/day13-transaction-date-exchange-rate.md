# 13일차: 거래일 환율 기반 손익

## 목표

미국 주식 거래의 원화 기준 손익에서 주가 변화와 환율 변화를 분리해 계산한다.

## 구현

- 미국 거래 시 거래일 USD/KRW 환율과 기준일을 원장에 저장
- 매도일 환율을 반영한 실현손익 및 주가 손익·환차익 분리
- 휴장일의 과거 환율 보정과 누락 환율 상태 처리
- 원화·달러 표시 전환과 환율 계산 테스트 추가

## 기준

- 현재 평가금액은 현재 환율을 사용한다.
- 과거 거래·차트는 기록에 저장된 거래일 환율을 사용한다.
- 필요한 환율이 없으면 임의 환산 대신 `환율 없음`으로 표시한다.
