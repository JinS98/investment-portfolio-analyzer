# 5일차: 포트폴리오 시각화와 리스크 분석

## 목표

현재 보유 비중과 가격 변동 정보를 차트와 리스크 지표로 이해할 수 있게 한다.

## 구현

- 시장·종목별 평가금액과 비중을 보여주는 포트폴리오 배분 차트
- 포트폴리오 성과 차트와 저장된 평가 이력의 기반 구성
- 변동성, 최대 낙폭, 집중도 기반 리스크 계산과 가이드 패널
- 이력·리스크 계산 단위 테스트 추가

## 기준

- 가격 데이터가 부족한 종목은 임의의 수치로 리스크를 만들지 않고 분석 불가 상태로 표시한다.
- 리스크 지표는 투자 판단을 대신하지 않는 참고 정보로 안내한다.
