# 18주차: 투자 분석과 운영 안정화

## 화면 구성

- 대시보드에서는 현재가 갱신 시각, 실패 종목, 자동매수 반영 건수와 실제 체결 확인 건수를 요약한다.
- 투자 분석에서는 적립식 투자 성과, 기준 지수 비교, 리스크 진단을 각각 독립 패널로 제공한다.
- 적립식 성과 상세는 대시보드의 `성과 분석 보기`에서 현재 사용자 배치에 있는 분석 패널 위치로 이동한다.

## 수익률 계산 기준

- 포트폴리오 비교 차트는 추가 매수와 매도에 따른 현금 흐름을 제거한 시간가중수익률을 사용한다.
- 코스피와 S&P 500은 포트폴리오와 공통으로 데이터가 존재하는 시작일을 0%로 맞춘다.
- 최고·최저 평가금액은 실제 평가금액이며, 최대 낙폭은 현금 흐름을 제거한 성과 지수를 기준으로 계산한다.

## 리스크 기준

- 시장 위험은 최근 90일 일봉의 연환산 변동성과 MDD를 사용한다.
- 집중 위험은 현재 평가금액과 활성 자동매수의 다음 1회 예상 금액을 합산한다.
- 리스크 단계 색상은 수익률의 빨강·파랑과 분리한다: 보통은 초록, 주의는 노란 주황, 기준 초과는 진한 주황이다.
- 일봉 조회에 실패한 종목도 분석 대상 수에 포함하고 `데이터 부족`으로 구분한다.

## 예외 상황

- 현재가 일부 조회 실패: 성공한 종목은 갱신하고 실패한 종목만 대시보드 알림에 표시한다.
- 지수 API 일부 실패: 조회된 지수와 포트폴리오 데이터는 계속 표시한다.
- 보유 종목 없음: 집중도 계산 대신 종목 추가 안내를 표시한다.
- 장기 이력: 현금 흐름을 날짜순으로 한 번만 순회해 이력과 거래 수 증가에 선형으로 대응한다.
- 실제 자동매수 미확정: 거래 내역으로 이동해 체결 가격·수량·비용을 확인한다.

## 점검 항목

- 모바일에서 대시보드 알림은 한 열로, 분석 카드와 표는 컨테이너 너비에 따라 재배치된다.
- 거래 내역 표와 종목별 리스크 표는 좁은 화면에서 해당 영역만 가로 스크롤한다.
- 시장 탐색 목록은 고정 높이 안에서 먼저 스크롤하며 상세 패널은 모바일 여백을 축소한다.
