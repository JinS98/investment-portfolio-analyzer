### 화면 검증 시 적용할 현재 레이아웃 기준

기준선 문서의 S07은 자유 배치 도입 전 상태를 기록합니다. 현재 화면에서는 자유 배치로 같은 행에 최대 3개 위젯을 놓을 수 있고, 계정·화면별 저장 키는 `dashboard-layout-v3:<userId 또는 guest>:<dashboard 또는 analysis>:<kind>` 형식입니다. `kind`는 `mode`, `basic`, `free` 중 하나입니다. 이전 `dashboard-panel-layout-v2` 값은 기본 배치를 읽을 때 마이그레이션 대상으로 사용합니다. 잘못된 자유 배치 값의 fallback을 시험할 때는 `dashboard-layout-v3:guest:dashboard:mode`를 `"free"`로 설정하고 `dashboard-layout-v3:guest:dashboard:free`에 잘못된 값을 넣어 새로고침합니다.
