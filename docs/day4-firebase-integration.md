# 4일차: Firebase 포트폴리오 연동

## 목표

로그인한 사용자의 포트폴리오와 종목 데이터를 Firebase에 저장하고 다시 불러온다.

## 구현

- Firebase Authentication과 Cloud Firestore 연결
- 사용자별 포트폴리오 저장·조회 및 로그인 상태 동기화
- 숫자 입력 포맷 유틸과 포트폴리오 갱신 상태·오류 상태 처리
- 대시보드가 저장된 포트폴리오를 기준으로 시세를 갱신하도록 연결

## 기준

- 사용자 데이터는 본인 경로만 읽고 쓸 수 있는 Firestore 규칙을 전제로 한다.
- 로그인 전후 전환 중 이전 사용자의 데이터가 화면에 남지 않게 한다.
