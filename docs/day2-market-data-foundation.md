# 2일차: 시장 데이터 조회 기반

## 목표

종목 코드 또는 이름으로 시세를 조회하고 대시보드에서 포트폴리오 평가에 사용할 수 있게 한다.

## 구현

- 토스증권 Open API의 가격·캔들·환율 응답을 프론트엔드용 타입으로 정규화
- 종목명·티커 검색 결과를 시장 구분(KR/US)과 함께 제공
- 시세 조회 패널과 포트폴리오 보유 종목의 현재가 갱신 흐름 구성
- 시장 데이터 파서와 기본 계산 테스트 추가

## 기준

- 숫자·문자열 혼합 API 응답을 서비스 계층에서 정리한다.
- 종목 코드의 앞자리 0은 보존하고, 실패한 응답은 화면 계산에 전달하지 않는다.
