# 14주차: 시장 탐색과 외부 정보

## 목표

시장 흐름을 탐색하고 찾은 종목을 포트폴리오 거래 입력으로 자연스럽게 연결한다.

## 구현

- 국내·미국 거래대금 순위, 지수, 종목 검색을 제공하는 시장 탐색 화면
- 종목 상세 시세·차트·관심 정보와 매수 기록 추가 동선
- 선택적 외부 정보 API(EODHD, 네이버, Marketaux)의 지표·뉴스 연동
- 검색·시장 데이터 요청 캐시와 최근 검색어 저장

## 기준

- 외부 정보 API가 없거나 실패해도 기본 시세·포트폴리오 기능은 유지한다.
- 시장별 순위는 거래 시간과 통화 차이를 고려해 분리해 안내한다.
