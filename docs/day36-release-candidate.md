## 핵심 흐름과 남은 확인

- 게스트 보유·실제/가상 원장 분리, 로그인 계정별 접근, 게스트 원장 이전·재시도, 적립식 투자 중복 방지는 자동 테스트로 확인했다. 실제 브라우저의 게스트 진입·로그인·새로고침·화면 이동은 [31일차 S01~S08](./day31-regression-verification.md)에 미실행으로 남아 있다. 36일차에는 연결 가능한 브라우저가 없어 화면 검증을 진행하지 못했다.
- 실제 Google OAuth 제공자, Functions 송신 IP, 토스 허용 IP 및 외부 API 응답은 에뮬레이터에서 확인할 수 없다. 39~40일차 검증 환경에서 확인한다.
- 새로 생성하는 기존 보유 이관 기록의 날짜를 이관일로 맞췄다. 과거 버전에서 이미 이관된 기록은 날짜를 변경하지 않고 출처를 `초기 보유 이관`으로 표시한다. [35일차 데이터 범위](./day35-release-documentation.md)에 지원 범위를 기록했다.
