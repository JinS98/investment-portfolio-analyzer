# 시장 탐색: 뉴스·재무정보 연동과 상세 패널 개선

## 목표

2026-10-17 기준 시장 탐색의 국내·미국 뉴스와 재무정보 연결 상태를 기록한다. 기존 배포 일정의 일차 번호와 별개인 기능 개선 기록이며, SEC 접근 차단을 연동 성공으로 판정하지 않는다.

## 구현

- 국내 뉴스는 NAVER API HUB 검색 API의 주소와 인증 헤더를 사용한다. 최신순 최대 3건, 제목·출처·날짜·원문 링크를 표시한다. 미국 뉴스는 기존 Marketaux 연동을 사용하며 사용자 화면에서 표시를 확인했다.
- OpenDART에서 기업코드를 연결하고 연간 매출액·영업이익·당기순이익·자산·부채·자본을 조회한다. 최신 제공 연도를 선택하고 연결재무제표를 우선하며 별도재무제표로 대체할 수 있다. 삼성전자 2025년 연결 자료의 실제 응답을 확인했다.
- 국내 PER·PBR·ROE·배당수익률은 DART의 연간 자료와 원화 현재가로 계산한다. PBR은 전체 유통주식수 기준 참고값으로 구분한다. 계산 기준과 공시 후 주식분할·증자 미반영 범위를 안내한다.
- 미국 SEC 기업목록·Submissions·Company Facts 연동을 추가했다. 같은 접수번호·기간·통화의 연간 자료만 조합하며 결산일·공시일·통화·원문 링크를 표시한다. 정정 보고서에 재무자료가 없으면 같은 연도 원 보고서를 확인한다.
- 국내 DART와 미국 SEC 모듈은 로컬 Vite 서버와 Functions에서 함께 사용한다. ESM 공통 모듈은 `.mts`로 관리하고 CommonJS Functions에서는 동적 import로 로드한다.
- 상세 패널 순서를 현재가 → 주가 그래프 → 재무제표 → 재무지표 → 뉴스로 통일했다. 제표·지표는 기본 접힘이며 키보드와 클릭으로 독립적으로 펼친다. 종목 변경 시 접힘 상태로 초기화한다.
- 공시 원문은 출처 영역의 보고서 링크로 정리하고 계산 설명은 지표 내부의 별도 펼침 영역에 배치했다. 상단 헤더 고정, 모바일 여백, 뉴스 제목 두 줄 표시, 숫자 단위 구분을 적용하고 제표·지표의 hover 배경색 변경은 제거했다.

## 기준

- 설정 파일의 실제 키와 연락 이메일은 커밋하지 않는다. 서버 환경변수에는 `VITE_` 접두사를 사용하지 않는다. 배포 시 Functions 환경에도 별도 설정한다.
- 누락 자료는 0으로 바꾸지 않고 `-`로 표시한다. 국내 제표는 원화 억 원, SEC 제표는 공시 통화의 백만 단위를 사용하며 표시 통화 설정에 따라 재무제표를 환산하지 않는다.
- 적자 EPS, 비양수 자본 등 계산이 적절하지 않은 지표는 `-`로 표시한다. ROE의 음수 이익은 유지한다.
- SEC 조회 실패와 해외 뉴스 응답을 분리한다. 브라우저의 `stock-insights`가 HTTP 200이어도 재무제표 영역에 SEC 실패 안내가 있을 수 있다.
- 기업 목록·정상 재무제표는 인스턴스별 하루 캐시, 종목 상세 응답은 15분 캐시한다. SEC는 요청 간격·동시 조회 병합·403/429 이후 10분 중단을 적용한다.

## 실제 연동 상태

| 항목               | 상태                                                                  |
| ------------------ | --------------------------------------------------------------------- |
| 국내 뉴스          | API HUB 전환 구현. 키 설정 경로와 인증 실패·한도 초과 안내 제공       |
| 미국 뉴스          | Marketaux 연동, 사용자 화면에서 표시 확인                             |
| 국내 재무제표·지표 | 삼성전자 실제 DART 자료와 토스 현재가로 조회·계산 확인                |
| 미국 재무제표      | 서버·화면 구현과 모의 응답 테스트 완료. 실제 SEC 요청은 403 차단 상태 |
| 미국 무료 재무지표 | 미구현. 기존 EODHD 연동이며 SEC 기반 무료 계산은 후속 작업            |

## 검증

검사 결과는 아래 명령과 실제 실행 기록으로 확인한다. 프런트 빌드·컴포넌트 테스트에는 로컬 기본 Node 22.11 대신 임시 Node 24를 사용했다. 의존성 버전과 잠금 파일은 변경하지 않았다.

- 타입 검사: `npm run typecheck`
- 정적 검사: `npm run lint`
- 단위·컴포넌트 테스트: `npm test`
- 프런트 빌드: `npm run build`
- Functions 빌드·API 테스트: `npm run build --prefix functions`, `npm test --prefix functions`
- 포맷·공백 검사: `npm run format:check`, `git diff --check`

## 남은 확인

1. SEC 차단 해제 또는 허용된 운영 환경의 접근 상태를 확인하고 실제 미국 기업 자료를 원문과 대조한다. 반복 요청이나 서버 재시작으로 차단이 해제된다고 가정하지 않는다.
2. 미국 재무지표를 무료 SEC 자료와 현재가로 계산하도록 교체한다. 종류주·ADR·주식분할 및 회계 기간을 별도 검증한다.
3. 배포 환경에 서버 전용 키·SEC 요청 식별 정보를 설정하고, 실기기·실제 데이터로 라이트/다크 및 반응형 화면을 확인한다.
